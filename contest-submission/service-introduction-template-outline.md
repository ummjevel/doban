# 서비스 소개서 템플릿 구성

원본 템플릿 파일:

`[서비스 소개서 양식] 한국관광공사 2026 관광 프롬프톤_팀명_제출자명 (사본 만들어서 사용하세요).pptx`

## 작성 기준

- 원본 템플릿은 반드시 사본으로 저장해서 사용
- 작성 완료 후 PDF, PPT, PPTX 중 하나로 저장하여 제출
- 페이지 추가 가능
- 전체 분량은 10장 내외 권장
- 발표 시간은 10분 이내 기준
- 1번 슬라이드 `양식 가이드`는 삭제 후 사용

## 슬라이드 구성

### 1. 양식 가이드

- 사본 저장 안내
- 제출 파일 형식 안내
- 페이지 추가 가능 안내
- 발표 시간 안내
- 제출 전 삭제 필요

### 2. 표지

- 팀명
- 서비스명
- 한 줄 설명
- 제출일
- 행사명: `2026 관광데이터 활용 공모전 - 생성형 AI 활용 관광 프롬프톤`

### 3. 팀 소개

- 팀 소개
- 사진
- 팀원 소개
- 참여 계기
- 팀원별 정보:
  - 성함
  - 담당 역할
  - 담당 업무
  - 기타사항

### 4. 서비스 소개 요약

- 서비스명
- 서비스 요약 설명
- 주제 선정 이유
- 타겟 사용자

### 5. 서비스 한 줄 요약 및 핵심 기능

- 서비스 한 줄 요약
- 권장 문장 형식: `우리는 OO한 문제를 OO를 통해 해결합니다.`
- 서비스 핵심 기능 3가지 이내

### 6. 서비스 입력 및 출력 1

- 입력값
- 예시 데이터
- 출력값
- 결과로 생성되는 내용 예시

### 7. 서비스 입력 및 출력 2

- 입력값
- 가변명 및 예시 데이터
- 출력값
- 결과로 생성되는 내용 예시
- 필요 시 페이지 추가 가능

### 8. 서비스 시연: 엔노이아 앱

- 엔노이아 앱 화면
- 출력 화면

### 9. 서비스 시연: 앱/웹 서비스 흐름

- 또는 주요 화면 흐름을 슬라이드로 표현

### 10. 서비스 시연 영상

- 서비스 개발에 활용한 한국관광공사 OpenAPI 외 API
