# 제출 가이드

## 제출 기본 안내

- 제출 방법: 팀 대표자가 결과물을 취합하여 제출
- 필수 제출 항목은 심사 대상 필수 조건 확인에 사용됨

> 유의 사항: 한국관광공사 OpenAPI 활용신청 정보(신청자명, 인증키, API 리스트)를 기반으로 심사대상 필수 조건인 공사 API 활용여부를 확인할 예정입니다. 따라서 정확한 정보를 입력해야 합니다.

## 필수 제출 항목

- 엔노이아 Studio 앱 공유 URL
- 서비스 소개서(별도 양식 제공)
- 한국관광공사 OpenAPI 활용 신청자명
- 한국관광공사 OpenAPI 활용 신청자 서비스 인증키
- 서비스 구현 시 활용한 한국관광공사 OpenAPI 리스트

## 선택 제출 항목

- 추가 참고 자료(기획안, 시연 영상 등)
- 서비스 관련 외부 링크

## STEP 01. 상세 설명 작성하기

### 서비스 제목은 무엇인가요?

- 서비스명, 기능명, 문제 해결 관점 모두 제목으로 입력 가능
- 예시: 지역 기반 맛집 추천 프롬프트, 여행 일정 자동 생성 AI 어시스턴트

### 서비스 내용을 요약 설명해주세요.

- 이 서비스가 무엇을 해결하는지, 어떤 결과를 내는지를 간단히 설명
- 세부 기능보다는 전체 개요 중심으로 작성
- 서비스가 나오게 된 로직 중심으로 설명해도 좋음

### 해당 주제를 선정한 이유는 무엇인가요?

- 왜 해당 주제를 선택했는지 자유롭게 작성
- 예시: 불편했던 경험, 평소 관심사 등

### 타겟 사용자는 누구인가요?

- 이 서비스를 주로 사용하게 될 사용자를 구체적으로 작성
- 예시: 국내여행객, 외국인여행객, 가족여행객, 단체여행객 등

### 공모전 수행 중 시행착오와 개선을 위한 시도가 있었나요?

- 프롬프트를 수정했던 경험, 원하는 결과가 나오지 않아 바꿨던 부분 등을 작성
- 특별히 없었다면 `없음`이라고 작성 가능

## STEP 02. 서비스 제출하기

### 필수 제출 1. 엔노이아 Studio 앱 공유 URL

- 팀에서 최종 완성한 산출물이 반영된 ennoia Studio 앱 공유 URL 제출
- 제출 방법:
  1. ennoia Studio 접속
  2. 제출할 앱 선택
  3. 더보기(...) 버튼 클릭
  4. 공유하기 메뉴 클릭
  5. 기본 값 또는 설정을 조정하여 공유 링크 생성 버튼 클릭
  6. 생성된 URL 링크를 복사하여 제출 폼에 입력

유의사항:

- 앱은 기본적으로 권한 사용자만 접근 가능하지만 공유 시 로그인 없이 모든 사용자 이용 가능
- 제출 전 직접 링크를 열어 정상 작동 여부 확인
- 링크 접속 시 결과물 확인이 어려운 경우 심사 대상에서 제외

### 필수 제출 2. 서비스 소개서

- 팀의 서비스 소개 자료 제출
- 자료는 10장 내외 권장
- 제출 폴더의 `service-introduction-template-outline.md`에 원본 PPTX 템플릿의 슬라이드별 작성 구조 정리
- 제출 형식:
  - PPT, PPTX 또는 PDF 파일 1부
  - 파일명 예시: `팀명_서비스소개서_서비스명`

작성 가이드:

- 팀 소개
- 서비스 결과물 소개
- 문제 정의
- 주요 기능
- 로직
- 기대효과
- 사용된 API 리스트
- 시행착오 및 개선 시도

발표 관련 참고:

- 예선 심사 통과 시 결선 심사에서 본 서비스 소개서를 활용하여 PT 발표 진행 예정
- 발표시간: 10분
- 결선 심사 진출 팀 대상 필요 시 자료 추가 수정 요청 가능
- 예선 심사 통과 이후 결선 발표를 대비하여 핵심 내용 중심으로 구성 권장

템플릿 활용 가이드:

1. 양식 바로가기 링크를 클릭하여 구글 슬라이드 양식 확인
2. 상단 메뉴의 `파일` > `사본 만들기` > `프레젠테이션 전체` 클릭
3. 본인의 드라이브로 복사한 후 내용 작성
4. 작성 완료 후 `파일` > `다운로드`에서 PDF 문서 또는 PPT, PPTX로 저장
5. 제출 폼에 업로드

### 필수 제출 3. 한국관광공사 OpenAPI 활용 신청자명

- 서비스 구현에 활용한 한국관광공사 OpenAPI 활용 신청자명 입력
- 엔노이아 API 커넥터에 연동한 한국관광공사 OpenAPI를 공공데이터포털에서 활용 신청한 사용자명 입력

### 필수 제출 4. 한국관광공사 OpenAPI 활용 신청자 서비스 인증키

- 서비스 구현에 활용한 한국관광공사 OpenAPI 활용 신청자의 API 인증키(서비스키) 입력
- 공공데이터포털 경로:
  1. 공공데이터포털 로그인
  2. 마이페이지
  3. 개인 API 인증키
  4. 인코딩키(Encoding), 디코딩키(Decoding) 복사
- 활용한 인증키를 모두 제출

### 필수 제출 5. 서비스 구현 시 활용한 한국관광공사 OpenAPI 리스트

## 선택 제출

보다 원활한 심사를 위해 아래 자료를 함께 제출할 수 있습니다.

- 추가 참고 자료: 상세 기획안, 시연 영상 등
- 서비스 관련 외부 링크: 엔노이아 앱 결과물 활용 앱/웹 서비스 URL, Notion, GitHub, Figma 등
