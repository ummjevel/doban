- 로컬 창업자 및 로컬 크리에이터

### Slide 8. 서비스 시연: Flow Chart 또는 앱/웹 흐름

원본 기준: 9번 슬라이드

원본 양식 항목:

- 앱/웹 서비스를 만들었다면 Flow Chart 혹은 슬라이드로 표현
- 페이지 추가 가능

작성 내용:

서비스 로직 흐름:

```text
사용자 질문 입력
-> 지역명/관광지명/업종/의도 추출
-> 관광지명인 경우 국문 관광정보 서비스로 주소/좌표 확인
-> 지역 코드 lookup으로 areaCd, signguCd 매핑
-> 필요한 한국관광공사 OpenAPI 선택 및 호출
-> 방문자/수요/자원/동선/웰니스 데이터 해석
-> 미니 컨설팅 리포트 생성
```

강조할 로직:

- 지역명과 관광지명을 구분한다.
- API별 코드 체계를 그대로 섞지 않고 지역 코드 lookup을 거친다.
- 한 API 결과만으로 결론을 내리지 않고 여러 데이터 신호를 조합한다.

발표 메시지:

- 도반은 질문을 바로 추천으로 바꾸지 않고, 지역 확인과 데이터 호출, 해석 단계를 거쳐 답변한다.

발표 시간:

- 1분 20초

### Slide 12. 기대효과, 발전계획, 마무리

원본 양식 항목:

작성 내용:

제품 관점:

- 예비창업자가 지역 후보와 창업 아이템을 빠르게 검토할 수 있다.
- 공공데이터 기반 미니 컨설팅 리포트를 즉시 생성할 수 있다.

사업 관점:

- 관광 상권 창업 전 사전 검토 도구로 활용 가능하다.

- 창업 체크리스트 자동 생성
