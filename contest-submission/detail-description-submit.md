# 상세 설명 제출용 초안

## 서비스 제목은 무엇인가요?

도반(Doban): 관광 데이터 기반 지역 창업 분석 챗봇

## 서비스 내용을 요약 설명해주세요.

도반(Doban)은 한국관광공사 OpenAPI를 활용해 특정 지역의 관광 흐름, 방문자 규모, 관광 수요 강도, 관광 자원 수요, 중심 관광지와 연관 관광 동선, 웰니스 관광 콘텐츠를 종합 분석하는 엔노이아 Studio 기반 챗봇입니다.

사용자가 `강릉에서 관광객 대상으로 창업하기 좋은 아이템 추천해줘`, `전주 한옥마을 근처에서 디저트 가게를 하면 괜찮을까?`처럼 지역과 창업 관심사를 입력하면, 도반은 관광지명 또는 지역명을 확인하고 관련 공공데이터를 호출한 뒤 미니 컨설팅 리포트 형태로 결과를 제공합니다.

결과는 단순 추천이 아니라 다음과 같은 구조로 제시됩니다.

- 한 줄 결론
- 분석 지역과 기준 데이터
- 방문자 및 관광 흐름 요약
- 체류, 소비, 관광 자원 수요 해석
- 중심 관광지와 연관 관광 동선 분석
- 추천 창업 아이템
- 리스크와 추가 확인사항

도반은 창업 성공이나 매출을 보장하지 않고, 공공데이터로 확인 가능한 신호와 한계를 함께 안내합니다. 이를 통해 예비창업자와 소상공인이 막연한 감이 아니라 관광 데이터 기반으로 지역 창업 방향을 검토할 수 있도록 돕습니다.

## 해당 주제를 선정한 이유는 무엇인가요?

지역 관광지 주변에서 창업을 고민할 때 많은 예비창업자와 소상공인은 `이 지역에 관광객이 충분한가`, `어떤 유형의 소비나 체험 수요가 있는가`, `어느 관광지를 중심으로 동선이 형성되는가`를 직접 판단하기 어렵습니다.

일반적인 여행 추천 서비스는 관광객에게 갈 곳을 알려주는 데 초점이 맞춰져 있지만, 창업자 입장에서는 관광객의 이동 흐름, 체류 가능성, 소비 신호, 관광 자원 수요를 함께 봐야 합니다. 그래서 관광 데이터를 창업 관점으로 재해석해주는 서비스가 필요하다고 판단했습니다.

도반은 한국관광공사 OpenAPI에 포함된 방문자수, 관광 수요 강도, 관광 자원 수요, 중심 관광지, 연관 관광지, 웰니스 관광정보를 조합해 지역 창업 의사결정에 필요한 기초 분석을 제공합니다. 특히 소규모 창업자가 전문 컨설팅을 받기 전에 빠르게 지역 후보와 아이템 방향을 검토할 수 있도록 돕는 것을 목표로 했습니다.

## 타겟 사용자는 누구인가요?

도반의 주요 타겟 사용자는 국내 관광 상권에서 창업 또는 업종 전환을 고민하는 사람들입니다.

- 국내 예비창업자
- 관광객 대상 매장을 준비하는 로컬 창업자
- 관광 상권에서 운영 중인 기존 소상공인
- 카페, 디저트, 식음료, 숙박, 체험, 웰니스 관련 창업을 검토하는 사용자
- 지역 관광 콘텐츠를 활용해 사업 아이템을 찾고 싶은 로컬 크리에이터

보조 타겟 사용자는 지역 관광 데이터를 바탕으로 창업 지원, 관광 콘텐츠 발굴, 로컬 비즈니스 기획을 검토하는 지자체 또는 관광 유관기관 담당자입니다.

## 공모전 수행 중 시행착오와 개선을 위한 시도가 있었나요?

있습니다.

초기에는 일반적인 여행지 추천 챗봇 방향도 검토했지만, 한국관광공사 OpenAPI를 더 의미 있게 활용하기 위해 관광객 대상 창업 분석 챗봇으로 방향을 좁혔습니다. 단순히 유명 관광지를 추천하는 방식은 공공데이터 활용성이 약하고 기존 서비스와 차별성이 낮다고 판단했기 때문입니다.

서비스 로직을 설계하면서 지역명 처리에서도 시행착오가 있었습니다. 사용자는 `강릉`, `해운대`, `전주 한옥마을`처럼 행정구역명과 관광지명을 섞어 입력할 수 있습니다. 하지만 API마다 요구하는 지역 코드 체계가 다르기 때문에, 지역명과 관광지명을 바로 API 파라미터로 사용할 수 없었습니다. 이를 개선하기 위해 지역명, 시군구 코드, 지표 코드 데이터를 엔노이아 문서 폴더에 업로드할 수 있는 CSV 형태로 정제했고, 관광지명은 국문 관광정보 서비스로 주소와 좌표를 확인한 뒤 데이터랩 계열 API의 지역 코드로 다시 매핑하는 흐름을 설계했습니다.

또한 답변 품질 측면에서는 창업 성공, 매출, 수익률을 단정하지 않도록 시스템 프롬프트를 조정했습니다. 관광 방문자수나 수요 지표는 창업 판단의 참고 신호일 뿐 실제 매출, 임대료, 경쟁 강도, 인허가를 대체할 수 없기 때문에, 도반의 답변에는 항상 데이터 근거와 한계, 추가 확인사항을 함께 포함하도록 개선했습니다.

## 서비스 구현 시 활용한 한국관광공사 OpenAPI 리스트

최종 제출 폼에는 실제 엔노이아 앱에서 사용한 API만 선택해야 합니다. 현재 도반 MVP 기준 활용 예정 API는 다음과 같습니다.

- 국문 관광정보 서비스
- 관광 빅데이터 정보 서비스
- 지역별 관광 수요 강도 정보 서비스
- 지역별 관광 자원 수요 정보 서비스
- 기초지자체 중심관광지 정보 서비스
- 관광지별 연관관광지 정보 서비스
- 웰니스 관광정보 서비스

## 제출 전 확인이 필요한 값

- 엔노이아 Studio 앱 공유 URL: 추후 입력
- 한국관광공사 OpenAPI 활용 신청자명: 전민정, 안중현
- 한국관광공사 OpenAPI 서비스 인증키: 제출 전 공공데이터포털에서 인코딩키와 디코딩키 확인 필요
- 최종 활용 OpenAPI 리스트: 실제 엔노이아 앱 연결 완료 후 최종 확정 필요
