# 상세 설명 제출용 초안

## 서비스 제목은 무엇인가요?

도반(Doban): 관광 데이터 기반 지역 창업 분석 챗봇

## 서비스 내용을 요약 설명해주세요.

도반(Doban)은 한국관광공사 OpenAPI를 활용해 지역 관광 흐름, 수요, 관광 자원, 동선을 분석하고 창업 아이템과 리스크를 미니 컨설팅 리포트로 제안하는 엔노이아 Studio 기반 지역 창업 분석 챗봇입니다.

## 해당 주제를 선정한 이유는 무엇인가요?

관광지 주변 창업은 방문자 수뿐 아니라 체류성, 소비 가능성, 관광 동선, 자원 수요를 함께 봐야 합니다. 도반은 관광 데이터를 창업 관점으로 재해석해 예비창업자와 소상공인이 지역과 아이템을 빠르게 검토하도록 돕고자 기획했습니다.

## 타겟 사용자는 누구인가요?

국내 관광 상권에서 창업·업종 전환을 고민하는 예비창업자, 기존 소상공인, 로컬 창업자·크리에이터이며, 보조 타겟은 지자체 및 관광 유관기관 담당자입니다.

## 공모전 수행 중 시행착오와 개선을 위한 시도가 있었나요?

공모전 수행 중 가장 큰 시행착오는 API별 코드 체계와 답변 품질 관리였습니다. 관광지명과 행정구역명이 섞여 입력될 수 있어, 국문 관광정보 서비스로 주소를 확인한 뒤 데이터랩 API용 지역 코드로 매핑하는 구조를 설계했습니다. 또한 지역명·시군구·지표 코드를 CSV로 정제해 엔노이아 문서 폴더에 업로드했습니다. 답변 측면에서는 고정 기준월이나 단일월 데이터에 의존하지 않도록 최신 기준월과 최근 3~6개월 흐름을 우선 확인하도록 조정했습니다. 창업 성공·매출·수익률을 단정하지 않도록 데이터 한계와 리스크, 추가 확인사항을 함께 제시하도록 프롬프트를 개선했습니다.

## 서비스 구현 시 활용한 한국관광공사 OpenAPI 리스트

최종 제출 폼에는 실제 엔노이아 앱에서 사용한 API만 선택해야 합니다. 현재 도반 MVP 기준 활용 예정 API는 다음과 같습니다.

- 국문 관광정보 서비스
- 관광 빅데이터 정보 서비스
- 지역별 관광 수요 강도 정보 서비스
- 지역별 관광 자원 수요 정보 서비스
- 기초지자체 중심관광지 정보 서비스
- 관광지별 연관관광지 정보 서비스
- 웰니스 관광정보 서비스

## 제출 전 확인이 필요한 값

- 엔노이아 Studio 앱 공유 URL: 추후 입력
- 한국관광공사 OpenAPI 활용 신청자명: 전민정, 안중현
- 한국관광공사 OpenAPI 서비스 인증키: 제출 전 공공데이터포털에서 인코딩키와 디코딩키 확인 필요
- 최종 활용 OpenAPI 리스트: 실제 엔노이아 앱 연결 완료 후 최종 확정 필요
